메뉴:menu
2가지 기능 중에서 하나 선택할 수 있게 창만 띄우기 각 기능으로 갈 수 있게 함수만 연결
1번 사용자가 입력 할 수 있게 하는 기능
2번 data.json파일을 분석하는 기능

1번 기능 파일:f1_function1
입력:
    사용자로 부터 필터 입력 2개(input1[3][3],input2[3][3])를 받고 
    패턴 입력 1(pattern[3][3])개를 받는다 
    입력 예외 처리 행열 수 불일치, 입력 형식이 다른지 확인한다
    입력 형식은 각 줄 3개의 숫자를 공백으로 구분하는 것

여기서 연산 함수를 불러 오기

계산 함수 만들기:f1_calculate 
각각 10번 for 해서 sum_time 에 넣기 
함수 호출시 연산 시간을 시작 하기
    2중 for문 사용해서 같은 자리 끼리 더해서 sum1에 넣기 
    sum1은 함수 안에서 초기화(매번 함수가 호출되면 새롭게 계산 하기 위해)
    sum+=input1[y][x]*pattern[y][x]

다시 같은 방식으로 하는데 여기서는 다시 시간 측정시작
그리고 sum2+=input2[y][x]*pattern[y][x] 하고 
연산 시간 끝내기 후 기록하기(sum_time)

평균시간 계산 해서 (sum_time/10:.3f) ave_time에 넣기
판정 결과 result에 넣기 
    result는 먼저 판정 불가 인지 확인 후 (sum1-sum2 절대값이 1e-9 보다 작은지 확인)
    판정이 가능하면 
반환:
함수 반환하기 여기서는 10회 평균시간과 각각의 점수 인 sum 반환 
return ave_time, sum1, sum2
